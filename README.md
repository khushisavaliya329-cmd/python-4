# Data Analyzer and Transformer Using Python

## Project Description
This project is a menu-driven Python program used to analyze and transform data using 1D and 2D lists. It supports manual and sample data input and demonstrates built-in functions, user-defined functions, `*args`, `**kwargs`, lambda functions, recursion, sorting, filtering, and basic data statistics.

## Features
- 1D and 2D list input
- Manual and sample data
- Basic statistics (sum, minimum, maximum, average)
- Duplicate value detection
- `*args` and `**kwargs`
- Recursive factorial and Fibonacci
- Lambda, map and filter
- Global variable
- Multiple return values
- Sorting in ascending and descending order

## Technologies Used
- Python
- VS Code

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run:

   `py "project 4.py"`

4. Select an option from the main menu.
